I.	Verifiable
-	Result of operation
-	Fill in the blank
-	Math questions
-	True/False
-	Multiple choice questions (with exceptions)
-	Operations necessary to achieve certain results
-	Matching terms
-	Select all that apply
These are simple checks to see whether the answer matches the answer key. 
Each question will only have a limited number of “correct answer”.
Multiple choices are NOT a good data for this category since multiple choice questions can be “gamed” to find the correct answer, unless it is necessary, multiple-choice questions should be translated into non-multiple-choice variant for testing. The non-multiple-choice variant can then be put under either verifiable or subjective.


II.	Subjective
a.	Against rubric
-	Explain cases
-	Interpretation of events
-	Report on projects/cases
b.	Not against rubric
-	Opinions
-	Reflections
“Rubric” here will not apply to formatting rubric or styles. Only for the content of the assignment.
For grading against a rubric, the answer must include enough keywords from the answer key or mentioned enough points from the key to be considered “passed”.
For grading not against rubric the models need to able to support its claims with real data from the resources given in the assignment.
